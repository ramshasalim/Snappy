# 🎮 Snappy

Snappy is a multiplayer web game where players can create or join private rooms and complete fun real-world challenges together.

Players receive random tasks based on the selected game settings. Once a challenge is completed, players upload a photo as proof, which is verified using AI before the game continues. The goal is to make real-world interactions more fun, engaging, and competitive.

🚧 **This project is currently in progress.**

## Planned Features

* Create and join private game rooms
* Random real-world challenges
* Multiple challenge categories and difficulty levels
* AI-powered image verification for completed tasks
* Real-time multiplayer gameplay
* Mobile-friendly interface

## Tech Stack

* HTML
* CSS
